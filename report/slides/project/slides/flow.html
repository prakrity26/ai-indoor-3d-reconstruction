How it works

Six steps from capture to sharing

01 · CAPTURE

Film the room

Any smartphone video.

02 · UPLOAD

Create a project

Web platform checks length, size and quality.

03 · PROCESS

Queue a job

A worker picks it up; progress shows live.

04 · RECONSTRUCT

Build the 3D room

COLMAP poses, then a mesh or a Gaussian splat.

05 · EXPLORE

Walk, orbit, tour

3D Studio and the first-person walk viewer.

06 · SHARE

Send a link

Read-only share link or website embed.

Indoor 3D Reconstruction

Walk through the six steps. The important design point: the API never does the heavy work itself. It stores the video and queues a job; a separate worker does the reconstruction.
