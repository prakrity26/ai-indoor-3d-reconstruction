The API only stores uploads, writes jobs to Postgres and serves files. Workers read jobs from the same table; Redis just wakes them up faster. The GPU worker runs on a rented cloud machine and talks to our side through the worker gateway, with a secret token, over a Cloudflare tunnel. To handle more videos, add more workers.
