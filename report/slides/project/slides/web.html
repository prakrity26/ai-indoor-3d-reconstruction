Backend and frontend

The platform people use

BACKEND · PYTHON 3.10

  • FastAPI + Uvicorn: REST API for uploads, jobs, files, sharing
  • SQLAlchemy: PostgreSQL in production, SQLite on a laptop
  • Redis: wakes workers when a job arrives
  • Workers: per-stage progress, retry, crash recovery

FRONTEND · NO BUILD STEP

  • Plain JavaScript modules: dashboard, upload, jobs, 3D Studio, sharing
  • Three.js: 3D graphics in the browser
  • GaussianSplats3D: renders the splat
  • Walk viewer: WASD, touch joystick, Walk / Orbit / Tour

Indoor 3D Reconstruction

The web platform has seven sections: Dashboard, My projects, Create project, Processing jobs, 3D Studio, Shared scenes, Settings. The walk viewer opens where the phone was held and faces the most detailed part of the room automatically.
