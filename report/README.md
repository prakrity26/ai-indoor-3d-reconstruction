# report/

Material for the project review and demo.

| File | What it is |
|---|---|
| [`PROJECT_REPORT.md`](PROJECT_REPORT.md) | Full report: what was built, the technology, timeline, problems solved, limitations, next steps |
| [`slides/`](slides/) | Source of the demo slide deck (14 slides with speaker notes) |

The deck is presented from its online slides page, which can also export to PowerPoint or PDF.
`slides/project/deck.json` lists the slides in order; each slide is one HTML file in
`slides/project/slides/`, with its speaker notes in the `<aside>` at the end. Images on the
slides are the previews in `samples/img1299/preview/`.
